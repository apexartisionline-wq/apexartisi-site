# Θεματικές της εβδομάδας (αρχεία)

Ένα αρχείο `.json` ανά εβδομάδα. Μπαίνει στο Apex σε κάθε ανέβασμα (`prisma/import-thematikes.ts`).
Μορφή και διαδικασία: `docs/odigies/thematiki-sto-apex.md`. Αρχεία με `"demo": true` μόνο στη δοκιμή.
Εδώ μπαίνουν ΜΟΝΟ κείμενα και ερωτήσεις — ποτέ απαντήσεις, ονόματα ή στοιχεία μελών.
