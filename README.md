# Apex

Η εφαρμογή της **apex/rtisi online**: μέλη, ομάδες, ατομικές, ημερολόγιο και κόκκινο κουμπί σε ένα μέρος.
Χτίζεται με βάση το έγγραφο «Apex — Σχέδιο εφαρμογής» (26/9/2026). Αυτό το repo περιέχει την **πρώτη φάση**.

Τεχνολογία: Next.js 15 (web app που «εγκαθίσταται» στο κινητό ως «Apex»), PostgreSQL μέσω Prisma.
Χωρίς κώδικα παρακολούθησης τρίτων· αυστηρό Content-Security-Policy.

## Τι κάνει ο καθένας

| Ρόλος | Διαδρομή | Τι κάνει |
| --- | --- | --- |
| Μέλος | `/m` | «Πού βρίσκομαι» (ατομικές Χ/8, ομάδες Υ/16), κείμενο της ημέρας, φόρμες θεματικής, «Μπες στην ομάδα» (Δ/Τ/Π 21:00, Σ 18:00 — η παρουσία μετράει μόνο από το κουμπί), ημερολόγιο, κράτηση ατομικών και Therapair (Δευτέρα έως 21:00, μόνο ώρες, ποτέ όνομα θεραπευτή), αίτημα αλλαγής/ακύρωσης έως 12 ώρες πριν, σχέδιο ασφάλειας, κόκκινο κουμπί |
| Θεραπευτής | `/t` | Πρόγραμμα ημέρας, εκκρεμότητες φροντίδας (24ω/7ημ μετά από κόκκινο κουμπί), κοινό σημείωμα συνεδρίας, σημείωμα ομάδας (θέμα / ατμόσφαιρα / «προσοχή σε…»), όλα τα μέλη, συνέπεια |
| Εύα | `/admin` | Εκκρεμότητες, θέσεις, ραντεβού (μετακίνηση, ακύρωση, έγκριση ζεύγους, εναλλαγή), αιτήματα, ομάδες και συντονιστές, εφημερίες, αρχείο κόκκινου κουμπιού (και άσκηση), αρχείο προσβάσεων, άνθρωποι, κείμενα, ρυθμίσεις |

Όλες οι ώρες, οι μέρες, τα δωμάτια Zoom, οι γραμμές βοήθειας και το όνομα είναι **ρυθμίσεις** (`/admin/settings`), όχι «καρφωμένα».
Όλες οι ώρες είναι ώρα Ελλάδας, ανεξάρτητα από τον server.

### Κόκκινο κουμπί
1. Πρώτο στην οθόνη: «Θέλω να μιλήσω με άνθρωπο». Από κάτω οι γραμμές βοήθειας, το σχέδιο ασφάλειας του μέλους, το μήνυμα από τον εαυτό του και η αναπνοή.
2. Ειδοποίηση πηγαίνει στον εφημερεύοντα και σε όλους τους θεραπευτές (Telegram με **μόνο το σύντομο όνομα**, push, και μέσα στο app).
3. Ο πρώτος που πατά «Το αναλαμβάνω» το παίρνει· το μέλος βλέπει «ο/η … σε παίρνει τώρα».
4. Αν δεν γίνει «Μιλήσαμε» μέσα στα λεπτά της ρύθμισης, ξαναστέλνεται και το μέλος βλέπει γραμμές βοήθειας και 112. Αν δεν το αναλάβει κανείς σε 10 λεπτά, κλιμακώνεται.
5. Μετά το «Μιλήσαμε» (με έκβαση, κρυπτογραφημένη) δημιουργούνται εκκρεμότητες φροντίδας 24 ωρών και 7 ημερών.
6. Η Εύα μπορεί να κάνει **άσκηση** από `/admin/help`, που δεν μετράει ως πραγματικό περιστατικό.

## Εγκατάσταση

```bash
cp .env.example .env        # συμπλήρωσε όλα τα πεδία (δες παρακάτω)
npm install
npm run db:deploy           # δημιουργεί τους πίνακες
ADMIN_USERNAME=eva ADMIN_NAME="Εύα" npm run db:seed   # τυπώνει τον πρώτο κωδικό
npm run build && npm start
```

Τοπικά: `npm run dev`, tests: `npm test`, έλεγχος τύπων: `npm run lint`.

### Μεταβλητές περιβάλλοντος
| Μεταβλητή | Τι είναι |
| --- | --- |
| `DATABASE_URL` | PostgreSQL σε περιοχή της ΕΕ |
| `APP_URL` | Η διεύθυνση της εφαρμογής |
| `DATA_KEY` | Κλειδί κρυπτογράφησης (`openssl rand -base64 32`). Σημειώματα, ημερολόγιο, σχέδια ασφάλειας, ηχογραφήσεις και εκβάσεις κόκκινου κουμπιού κρυπτογραφούνται με αυτό. **Φυλάσσεται χωριστά από τα αντίγραφα της βάσης· αν χαθεί, τα δεδομένα δεν διαβάζονται.** |
| `CRON_SECRET` | Για το `/api/cron/tick` |
| `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT` | Ειδοποιήσεις push (`npx web-push generate-vapid-keys`) |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `TELEGRAM_WEBHOOK_SECRET` | Κόκκινο κουμπί στο Telegram |

### Κάθε λεπτό (cron)
```bash
curl -X POST -H "Authorization: Bearer $CRON_SECRET" $APP_URL/api/cron/tick
```
Κάνει: επανάληψη/κλιμάκωση κόκκινου κουμπιού, υπενθυμίσεις φροντίδας, ειδοποιήσεις μελών
(κείμενο, φόρμες, ομάδα, ημερολόγιο, συνεδρία — όχι 22:00–08:00, μία φορά η καθεμία),
ειδοποιήσεις αποχής. Το παλιό `/api/cron/help` δουλεύει ακόμα και κάνει το ίδιο.

### Φιλοξενία (δεδομένα στην Ευρώπη)
Χρειάζεται μια βάση PostgreSQL και ένας Node.js server, και τα δύο σε περιοχή της ΕΕ
(π.χ. Frankfurt). Οποιοσδήποτε πάροχος κάνει· σημασία έχει η περιοχή και η σύμβαση επεξεργασίας (DPA).

### Telegram
1. Δημιουργία bot με τον @BotFather → `TELEGRAM_BOT_TOKEN`.
2. Προσθήκη του bot στην ομάδα των θεραπευτών → `TELEGRAM_CHAT_ID` (αρνητικός αριθμός).
3. Webhook:
   ```bash
   curl "https://api.telegram.org/bot$TELEGRAM_BOT_TOKEN/setWebhook" \
     -d url="$APP_URL/api/telegram" -d secret_token="$TELEGRAM_WEBHOOK_SECRET" \
     -d allowed_updates='["callback_query"]'
   ```
4. Σε κάθε θεραπευτή, στο `/admin/people`, το Telegram user ID του (για να φαίνεται το σωστό όνομα).

### Ασφάλεια προσωπικού
Οι θεραπευτές και η Εύα μπαίνουν με κωδικό και δεύτερο βήμα (εφαρμογή authenticator), όταν είναι ενεργό στις ρυθμίσεις.
Κάθε άνοιγμα φακέλου μέλους, σημειώματος ή σχεδίου ασφάλειας γράφεται στο `/admin/audit`.
