# 03 — Αξιολόγηση κινδύνου αυτοκτονίας, αυτοτραυματισμού και υπερδοσολογίας

**Πότε:**
- στην αρχική αξιολόγηση (02) — **πριν δοθεί κωδικός**
- μετά από υποτροπή (χρήση ή τζόγο) που μαθαίνουμε
- μετά από πάτημα του κόκκινου κουμπιού (από όποιον ανέλαβε, στη συζήτηση ή την επόμενη μέρα)
- όταν το μέλος απαντήσει «ναι» σε σκέψεις αυτοτραυματισμού στο ημερολόγιο (την επόμενη εργάσιμη, στην πρώτη επαφή — βλ. README)
- μετά από 3 μέρες χωρίς επαφή, όταν ξαναβρεθεί
- σε κάθε ανανέωση κύκλου (μετά την 8η ατομική)
- όποτε ο θεραπευτής ανησυχεί, ή μετά από μεγάλη απώλεια (χωρισμός, πένθος, απόλυση, μεγάλη χασούρα, σύλληψη)

**Ποιος:** όποιος θεραπευτής έχει την επαφή (βιωματικός ή κλινικός). Ο **μέτριος** και ο **υψηλός** κίνδυνος πηγαίνουν την ίδια μέρα σε κλινικό ψυχολόγο (σήμερα: Χριστιάνα, Μένη) και στην Εύα.
**Πόσο χρόνο:** 5–10′ (πλήρης στην ένταξη ~15′).

**Σκοπός:** δεν «προβλέπουμε» ποιος θα αυτοκτονήσει. Αποφασίζουμε **τι κάνουμε τώρα** και ενημερώνουμε το πλάνο ασφάλειας (04).

---

## 1. Πώς ρωτάς

- Ρώτα ευθέως. Η ερώτηση για αυτοκτονία **δεν** βάζει την ιδέα στο μυαλό κάποιου· συνήθως ανακουφίζει.
- Χρησιμοποίησε τη λέξη «αυτοκτονία» ή «να πεθάνεις» — όχι «βλακεία».
- Σε Zoom: βεβαιώσου στην αρχή ότι ξέρεις **πού βρίσκεται τώρα** και σε ποιο τηλέφωνο θα τον/την βρεις αν κοπεί η σύνδεση.
- Αν κοπεί η σύνδεση σε συζήτηση κινδύνου: κάλεσε αμέσως στο κινητό. Αν δεν απαντά σε 5′ και ο κίνδυνος ήταν μέτριος/υψηλός → επαφή έκτακτης ανάγκης / 112 (βλ. §4).

## 2. Ερωτήσεις (δική μας διατύπωση)

Αν είναι διαθέσιμο με άδεια, μπορεί αντί για το 2α να χρησιμοποιηθεί το **C-SSRS screener** στην επίσημη σταθμισμένη ελληνική έκδοση (δεν αναπαράγεται εδώ· όροι χρήσης από Columbia Lighthouse Project — να επιβεβαιωθούν). Καταγράφεται τότε το αποτέλεσμα κατά τις οδηγίες του εργαλείου.

Σκέψεις να κάνει κακό σε κάποιον; ☐ όχι ☐ ναι → ⚠ κλιμάκωση ίδια μέρα. Παιδιά σε κίνδυνο; ☐ όχι ☐ ναι → ⚠ κλιμάκωση ίδια μέρα (βλ. 02, §10α).

## 3. Κίνδυνος υπερδοσολογίας

**Το πιο σημαντικό μήνυμα:** μετά από διάστημα αποχής (μονάδα, ΑΥΤΟΓΝΩΣΙΑ PLUS, φυλακή, νοσοκομείο, ή απλώς μερικές μέρες/εβδομάδες καθαρός/ή) **η ανοχή πέφτει**. Η «παλιά δόση» μπορεί να σκοτώσει. Αυτό ισχύει κυρίως για οπιοειδή (ηρωίνη, μεθαδόνη, χάπια), αλλά και για αλκοόλ με βενζοδιαζεπίνες.

| Ερώτηση | Ναι/Όχι |
|---|---|
| Κάνει/έκανε χρήση οπιοειδών; | |
| Πόσο καιρό είναι σε αποχή; (ημέρες) | |
| Έχει πάθει υπερδοσολογία ποτέ; Τελευταίους 12 μήνες; | |
| Συνδυάζει ουσίες (οπιοειδή + αλκοόλ + βενζοδιαζεπίνες/πρεγκαμπαλίνη); | |
| Κάνει χρήση μόνος/η; | |
| Ενδοφλέβια χρήση; | |
| Αγοράζει από άγνωστη πηγή (κίνδυνος νοθείας, π.χ. με φαιντανύλη/νιταζένια); | |
| Μόλις βγήκε από μονάδα/φυλακή/νοσοκομείο (τελευταίες 4 εβδομάδες); | |
| Έχει ναλοξόνη στο σπίτι; Ξέρουν οι δικοί του να τη χρησιμοποιούν; | |

**Τι λες στο μέλος (χωρίς κήρυγμα):**
«Δεν σου λέω ότι θα κάνεις χρήση. Σου λέω τι να ξέρεις αν συμβεί: η αντοχή σου έχει πέσει. Αν γίνει, μην είσαι μόνος/η, πάρε πολύ λιγότερο, μη συνδυάζεις με ποτό ή χάπια, και πάτα το κόκκινο κουμπί — πριν ή μετά, δεν έχει σημασία.»

**Ναλοξόνη:** αντίδοτο στα οπιοειδή (ρινικό σπρέι ή ένεση). Αν το μέλος κάνει/έκανε χρήση οπιοειδών, συζητάμε πώς μπορεί να την έχει ο ίδιος και οι δικοί του. **Διαθεσιμότητα στην Ελλάδα (συνταγή, φαρμακείο, προγράμματα ΕΟΠΑΕ/μείωσης βλάβης) — να επιβεβαιωθεί από την Εύα και να γραφτεί εδώ.** Σε κάθε πιθανή υπερδοσολογία: **112 ή ΕΚΑΒ 166 πάντα**, ακόμη κι αν δόθηκε ναλοξόνη (η δράση της μπορεί να περάσει πριν περάσει η ουσία).

**Σημάδια υπερδοσολογίας (να τα ξέρουν μέλος και οικογένεια):** δεν ξυπνά, πολύ αργή/ροχαλητή ή καθόλου αναπνοή, μπλε χείλη/νύχια, κόρες «καρφίτσα». → 112/166, πλάγια θέση, ναλοξόνη αν υπάρχει, μην τον/την αφήνεις μόνο/η.

## 4. Επίπεδο κινδύνου και τι κάνεις

Το επίπεδο είναι **κλινική κρίση**, όχι άθροισμα. Αν διστάζεις ανάμεσα σε δύο, διάλεξε το υψηλότερο.

### ΧΑΜΗΛΟΣ
*Π.χ. «ναι» μόνο στην ερώτηση 1 ή σε περαστικές σκέψεις χωρίς τρόπο και πρόθεση· χωρίς πρόσφατη απόπειρα· καλοί προστατευτικοί παράγοντες.*
- Έλεγξε/ενημέρωσε το πλάνο ασφάλειας (04) μαζί.
- Θύμισε κόκκινο κουμπί και γραμμές βοήθειας.
- Κατέγραψε στο σημείωμα· επανεκτίμηση στην επόμενη ατομική.

### ΜΕΤΡΙΟΣ
*Π.χ. σκέψεις με τρόπο (ερ. 3) χωρίς πρόθεση/σχέδιο· ή αυτοτραυματισμός χωρίς πρόθεση θανάτου πρόσφατα· ή απόπειρα πάνω από 3 μήνες πριν μαζί με τωρινούς παράγοντες κινδύνου· ή υψηλός κίνδυνος υπερδοσολογίας (π.χ. πρόσφατη υποτροπή σε οπιοειδή μετά από αποχή).*
- Πλάνο ασφάλειας **τώρα, μέσα στη συνεδρία** — με έμφαση στο «πώς κάνω το περιβάλλον ασφαλέστερο» (04, βήμα 6).
- Συμφωνήστε ποιος θα τον/την πάρει τηλέφωνο και πότε (μέσα σε 24 ώρες).
- **Ίδια μέρα:** τηλεφωνική ενημέρωση κλινικού ψυχολόγου + Εύας. Ο κλινικός ψυχολόγος αποφασίζει αν χρειάζεται έκτακτη ατομική ή παραπομπή σε ψυχίατρο.
- Με συναίνεση: ενημέρωση ατόμου στήριξης / επαφής έκτακτης ανάγκης.
- Ναλοξόνη, αν αφορά.
- Επανεκτίμηση μέσα σε 48–72 ώρες.

### ΥΨΗΛΟΣ
*Π.χ. πρόθεση ή σχέδιο (ερ. 4 ή 5)· απόπειρα ή προετοιμασία τους τελευταίους 3 μήνες· πρόσβαση σε μέσα και απελπισία· μέθη με σκέψεις αυτοκτονίας· αδυναμία να συμφωνήσει σε ασφάλεια.*
- **Μην κλείσεις την επικοινωνία.** Μείνε στο Zoom ή στο τηλέφωνο.
- **Άμεσος κίνδυνος** (έχει πάρει κάτι, έχει τα μέσα μπροστά του/της, δεν μπορεί να κρατηθεί ασφαλής): **112** (ή **ΕΚΑΒ 166** για ιατρικό επείγον / υπερδοσολογία) με τη **διεύθυνση από τον φάκελο**. Σε αυτή την περίπτωση δεν χρειάζεται συναίνεση — η ζωή προηγείται (νομική διατύπωση να ελεγχθεί).
- Αν δεν είναι άμεσος: βοήθησε να απομακρυνθούν τα μέσα, κάλεσε (με το μέλος) άτομο να έρθει να μείνει μαζί του/της, οδήγησε σε **εφημερεύον ψυχιατρείο/νοσοκομείο** (ποτέ να οδηγήσει ο ίδιος/η ίδια σε αυτή την κατάσταση).
- Δώσε **1018** (γραμμή για την αυτοκτονία) και 112.
- **Αμέσως** τηλεφώνησε σε κλινικό ψυχολόγο και Εύα (ή εφημερεύοντα το βράδυ). Αν δεν απαντούν, προχώρα με 112 — μην περιμένεις.
- Επαφή μέσα στις επόμενες 24 ώρες (ορίζεται ποιος), ακόμη κι αν νοσηλευτεί.
- Αναφορά συμβάντος (έντυπο κρίσης) την ίδια μέρα.

**Αριθμοί (να επιβεβαιωθούν πριν τη δοκιμή):** 112 έκτακτη ανάγκη · 166 ΕΚΑΒ · 1018 γραμμή παρέμβασης για την αυτοκτονία · 10306 γραμμή ψυχικής υγείας · 1031 γραμμή για τις εξαρτήσεις.
