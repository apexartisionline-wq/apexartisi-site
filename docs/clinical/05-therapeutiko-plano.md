# 05 — Εξατομικευμένο θεραπευτικό πλάνο

**Πότε:** συντάσσεται μέσα στις 2 πρώτες εβδομάδες (έως την 2η ατομική) και ανασκοπείται σε κάθε μηνιαία ανανέωση κύκλου (όταν κλείσουν οι 8 ατομικές).
**Ποιος:** ο θεραπευτής της 1ης ή 2ης ατομικής, μαζί με το μέλος· την ανασκόπηση την κάνει όποιος έχει την 8η ατομική του κύκλου ή την πρώτη του νέου. Η Εύα βλέπει και σημειώνει «ελέγχθηκε».
**Πόσο χρόνο:** σύνταξη ~15′ μέσα στη συνεδρία + 10′ μετά· μηνιαία ανασκόπηση ~10′.

Επειδή δεν υπάρχει υπεύθυνος θεραπευτής ανά μέλος, το πλάνο είναι το «νήμα» που κρατά τη συνέχεια: κάθε θεραπευτής το διαβάζει πριν την ατομική και γράφει στο σημείωμα σε ποιον στόχο δούλεψε.

## 2. Στόχοι (2–4, με τα λόγια του μέλους)

Κανόνας: ο στόχος γράφεται όπως τον είπε το μέλος, σε εισαγωγικά. Δίπλα, ο θεραπευτής τον μετατρέπει σε βήματα που μετριούνται. Όχι περισσότεροι από 4.

| # | Στόχος (λόγια μέλους) | Μετρήσιμα βήματα | Πώς θα το δούμε | Έως |
|---|---|---|---|---|
| 1 | «…» | π.χ. 4 ομάδες/εβδομάδα, ημερολόγιο 6/7 βράδια | Συνέπεια στο app | τέλος κύκλου |
| 2 | «…» | π.χ. 1 τηλεφώνημα την εβδομάδα σε άτομο στήριξης | αναφορά στην ατομική | |
| 3 | «…» | | | |
| 4 | «…» | | | |

Παραδείγματα καλής διατύπωσης βημάτων: «Να μην έχω μετρητά πάνω από 20€ τις Παρασκευές», «Να κοιμάμαι πριν τη 01:00 τουλάχιστον 5 βράδια», «Να πατήσω το κόκκινο κουμπί πριν από το πρώτο ποτό, όχι μετά». Αποφεύγουμε: «να γίνω καλύτερος», «να μην υποτροπιάσω ποτέ».
