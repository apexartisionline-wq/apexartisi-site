# Η θεματική της εβδομάδας μέσα στο Apex (από 22/10/2026)

Η υπεύθυνη γράφει τα κείμενα και τις φόρμες της θεματικής με το Claude, όπως πριν. Αντί για Google Forms, το αποτέλεσμα
είναι **ένα αρχείο** στο `content/thematikes/`, που μπαίνει μόνο του στο Apex σε κάθε ανέβασμα. Τα μέλη απαντούν μέσα
στο Apex («Βιβλιοθήκη θεματικών»)· η ομάδα βλέπει τις απαντήσεις στον φάκελο του μέλους («Εργασίες»).

## Κάθε εβδομάδα (για το Claude)
1. Γράφουμε μαζί τη θεματική: θέμα, τα 3 κείμενα (Δευτέρα, Τετάρτη, Παρασκευή) και τις ερωτήσεις κάθε φόρμας.
2. Αποθηκεύεις **ένα** αρχείο `content/thematikes/ΥΥΥΥ-ΜΜ-ΗΗ-θέμα.json` (ΗΗ = η Δευτέρα της εβδομάδας), μορφή παρακάτω.
3. Τρέχεις τοπικά `npx tsx prisma/import-thematikes.ts` (με τη βάση της δοκιμής του container) και δείχνεις στην υπεύθυνη
   πώς φαίνεται η φόρμα στο μέλος (εικόνα κινητού).
4. Με το «ναι» της: commit + push στον κλάδο· σε ~5′ η θεματική είναι στο Apex και βγαίνει μόνη της στα μέλη την ώρα
   των φορμών («Ρυθμίσεις»). Ιδανικά Παρασκευή ή Σάββατο για την επόμενη εβδομάδα.
5. Ποτέ απαντήσεις, ονόματα ή στοιχεία μελών μέσα στα αρχεία — μόνο κείμενα και ερωτήσεις.

## Μορφή του αρχείου
```json
{
  "theme": "Όρια",
  "forms": [
    { "date": "2026-10-26", "title": "Όρια — Φόρμα 1", "body": "Το κείμενο της ψυχοεκπαίδευσης…", "questions": ["Ερώτηση 1", "Ερώτηση 2"] },
    { "date": "2026-10-28", "title": "Όρια — Φόρμα 2", "body": "…", "questions": ["…"] },
    { "date": "2026-10-30", "title": "Όρια — Φόρμα 3", "body": "…", "questions": ["…"] }
  ],
  "texts": [
    { "date": "2026-10-26", "title": "Ξεκινάμε τη μέρα παρέα — τίτλος", "body": "Προαιρετικά: τα κείμενα της ημέρας της εβδομάδας." }
  ]
}
```
- `questions`: 1–30 ερωτήσεις ανοιχτού κειμένου (το μέλος απαντά σε κουτί). Επιλογές/κλίμακες: όχι ακόμα.
- `texts`: προαιρετικό. Η εικόνα της «Καθημερινής σκέψης» ανεβαίνει από τη διαχείριση («Κείμενα»), όχι από αρχείο.
- `"demo": true`: μόνο στη δοκιμή (DEMO_SEED=1) — για ψεύτικες θεματικές ελέγχου.

## Διορθώσεις
- Αλλάζεις το ίδιο αρχείο και ξαναγίνεται push: ενημερώνεται κείμενο/ερωτήσεις **μόνο αν δεν έχει απαντήσει κανείς**.
  Αν υπάρχουν απαντήσεις, η φόρμα μένει ως έχει (οι απαντήσεις είναι δεμένες με τις ερωτήσεις)· για αλλαγή, νέα φόρμα με
  άλλον τίτλο.
- Αλλαγή του τίτλου = νέα φόρμα. Τίποτα δεν σβήνεται από αρχείο· σβήσιμο φόρμας χωρίς απαντήσεις μόνο από τη διαχείριση.
- Επείγουσα αλλαγή χωρίς ανέβασμα: η διαχείριση φτιάχνει φόρμα στο «Κείμενα» (πεδίο «Ερωτήσεις», μία σε κάθε γραμμή).

## Τι γίνεται με τις παλιές Google Forms
Μένουν όπως είναι (σύνδεσμοι στη «Βιβλιοθήκη θεματικών», με τη συγκατάθεση «φόρμες σε Google»). Οι απαντήσεις τους
μένουν στη Google και δεν φαίνονται στο Apex.
